1.1. Abstract
This document specifies which of the pre-approved data formats — CSV, JSON, HTML, XML,
ARXML, XSLX, PICKLE, DB — apply to which X Paradox X data concern, elaborating the original
format-list baseline directive into concrete, per-use-case selection rules.

1.2. Key Words
data format, CSV, JSON, HTML, XML, ARXML, XLSX, pickle, database, save file, export, security.

1.3. Executive Summary
X Paradox X uses JSON as its primary save-file and structured-log-export format, CSV/XSLX
for tabular statistics export, and reserves HTML/XML/ARXML/DB for specific downstream/
reporting use cases; PICKLE is explicitly restricted per the security guidance in Section
1.10, consistent with OWASP guidance against deserializing untrusted pickled data.

1.4. Key Findings
1.4.1. All eight formats named in the original baseline directive (Section 1.6) remain
approved formats for this project; this document assigns each to concrete use cases rather
than removing any.
1.4.2. JSON is the primary format for save files (015_game_deployment.txt Section 1.7.1) and
structured statistics (010_game_player_statistics.txt Section 1.9.1), for human-readability
and broad tooling support.
1.4.3. CSV and XSLX (XLSX) are reserved for tabular statistics export/analysis, useful for
the balance-simulation review described in 012_game_perfomance_tests.txt Section 1.6.5.
1.4.4. PICKLE is restricted to trusted, locally-generated, same-version data only (e.g.
ephemeral development-only caches), and must never be used to deserialize data from an
untrusted or external source, per OWASP guidance on insecure deserialization.
1.4.5. HTML, XML, ARXML, and DB formats are reserved for future/optional reporting,
interchange, or persistence needs not required by the MVP, and are not currently wired into
any required MVP data path.

1.5. Philosophical Preamble
A data format is a security boundary as much as a serialization choice. This document keeps
faith with the original baseline's full format list while making explicit which formats are
safe defaults and which (PICKLE, in particular) require a narrower, trust-bounded use case,
in keeping with this project's OWASP Top 10 security discipline.

1.7. Format Selection Criteria and Use Cases
| Format | Primary Use Case in X Paradox X |
|--------|-------------------------------------|
| JSON | Save files (1.8), structured statistics export, event-log export |
| CSV | Tabular statistics export for spreadsheet/analysis tools |
| XSLX (XLSX) | Tabular statistics export where formatting/multi-sheet support is desired |
| HTML | Optional human-readable statistics/report rendering (reserved, not MVP-required) |
| XML | Optional structured interchange with external tooling (reserved, not MVP-required) |
| ARXML | Reserved for potential future AUTOSAR-style structured interchange (reserved, not MVP-required; no current use case) |
| PICKLE | Trusted, same-version, locally generated ephemeral caches only; never for untrusted/external data (Section 1.10) |
| DB | Reserved for a potential future embedded database persistence layer (reserved, not MVP-required) |

1.8. Save File Format
Save files (015_game_deployment.txt Section 1.7.1) are serialized as JSON: human-readable,
diffable, and free of the arbitrary-code-execution risk associated with PICKLE
deserialization, consistent with OWASP secure-deserialization guidance.

1.9. Statistics Export Formats
Player/session statistics (010_game_player_statistics.txt) may be exported as JSON (default,
structured), CSV, or XSLX (for spreadsheet analysis, e.g. during the balance-simulation
review in 012_game_perfomance_tests.txt Section 1.6.5).

1.10. Data Format Prohibitions
1.10.1. PICKLE must never be used to load data from an untrusted or externally supplied
source (e.g. a shared save file from an unknown origin), since Python's `pickle` module can
execute arbitrary code during deserialization; this is a binding OWASP-aligned security rule,
not merely a style preference.
1.10.2. Save files and any player-shareable data must use JSON, never PICKLE, specifically
because save files may be shared between users/devices.
