1.1. Abstract
This document defines the supported game modes for X Paradox X: the MVP local pass-and-play
mode and the optional AI Adviser feature, and explicitly defers all other modes (online
multiplayer, fully autonomous AI opponents) to 018_future_wishlist_items.txt, per
001_game_concept.txt Section 1.9.

1.2. Key Words
game modes, local pass-and-play, AI adviser, Consult the Oracle, advisory-only, heuristic
fallback, deferred modes.

1.3. Executive Summary
X Paradox X ships exactly one playable mode at MVP: two-player local pass-and-play. Layered
on top of it is an optional, advisory-only AI feature, "Consult the Oracle," which recommends
one legal move, one alternative, an explanation, and a risk rating, without ever mutating
game state directly. All other conceivable modes (online multiplayer, autonomous AI
opponents, ranked play) are explicitly out of MVP scope and tracked in
018_future_wishlist_items.txt.

1.4. Key Findings
1.4.1. Local pass-and-play is the only mode required to be functional for the hackathon
demo, per 001_game_concept.txt Section 1.9.1.
1.4.2. The AI Adviser must never directly mutate game state; every suggested command is
validated by the same rules engine that validates human player commands, per
003_game_philosophy.txt Section 1.6.3.
1.4.3. If no external AI service is configured or reachable, the Adviser falls back to a
deterministic heuristic recommender so the feature remains demonstrable without a live
network dependency, retained unchanged from the original ideation session.
1.4.4. A one-player-vs-autonomous-AI mode and online multiplayer are both explicitly
deferred, per the original ideation session's own MVP scoping ("One simple AI opponent only
if time permits... No online multiplayer").
1.4.5. The Adviser's recommendations are computed from a compact, serialized game-state
summary, not a live reference to mutable engine state, per 006_game_scaffolding.txt Section
1.7.

1.5. Philosophical Preamble
A "mode" is a promise about what kind of agency the player has surrendered, if any, to
automation. X Paradox X's philosophy (003_game_philosophy.txt Section 1.6.3) draws a hard
line: automation may advise, but the player and the deterministic rules engine remain the
sole authorities over outcomes. This principle is what allows an AI feature to exist in a
hackathon-scale prototype without threatening the game's core promise of auditable fairness.

1.6. Local Pass-and-Play Mode (MVP)
1.6.1. Two players share one device; turns alternate strictly per the phase order in
017_game_rules.txt Section 1.8.
1.6.2. No account, login, or network connection is required.
1.6.3. Match state autosaves locally per 015_game_deployment.txt persistence rules, allowing
a paused match to be resumed via Continue Game (004_game_menu_context_menus.txt Section
1.7.6).

1.7. AI Adviser Mode ("Consult the Oracle")

1.7.1. Adviser Input Contract
A compact, serialized summary of the current game state: board size, piece positions and
HP, territory ownership, credits, Dominion Points, current hand (for the requesting player
only), and turn/phase.

1.7.2. Adviser Output Contract
| Field | Description |
|-------|--------------|
| Recommended move | One legal command (per 017_game_rules.txt mechanics) |
| Alternative move | One additional legal command |
| Explanation | A concise, plain-language rationale |
| Risk rating | Low, Moderate, or High |

1.7.3. Adviser Constraints
1.7.3.1. The Adviser never mutates game state; it only returns a recommendation.
1.7.3.2. Every Adviser-suggested command is passed through the same rules-engine validation
path as a human-issued command before it can be previewed to the player (see
004_game_menu_context_menus.txt Section 1.9 two-step confirm model).
1.7.3.3. The Adviser must not introduce new rules, cards, pieces, or mechanics not defined in
017_game_rules.txt.

1.7.4. Deterministic Heuristic Fallback
If no external AI/model service is configured or reachable, the Adviser uses a deterministic,
rules-based heuristic (e.g. prefer moves that capture an undefended territory, then moves
that avoid an unfavorable combat trade) so the feature remains demonstrable offline, retained
unchanged from the original ideation session.

1.8. Deferred Modes
The following modes are explicitly out of MVP scope and tracked in
018_future_wishlist_items.txt: fully autonomous single-player AI opponent (beyond the
advisory Oracle), ranked/competitive online multiplayer, spectator mode, and any mode
requiring user accounts.

1.13. Conclusion

feature, with all further modes explicitly deferred and tracked for future consideration.
