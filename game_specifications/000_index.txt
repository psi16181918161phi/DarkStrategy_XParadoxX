1.1. Abstract
This document is the master index for the game_specifications/ corpus governing X Paradox X,
the first title published under the X Dark X company banner in the Dark Strategy (DS) genre.
It enumerates every specification file in this directory, states its purpose, its compliance
status against game_specifications/0000_documentation_standards.txt, and its dependency
relationships to sibling documents. This index must be updated whenever a file is added,
removed, or renumbered, per Section 1.6.7 of 0000_documentation_standards.txt.

1.2. Key Words
index, registry, X Paradox X, X Dark X, Dark Strategy, DS, document map, cross-reference,
dependency, compliance status, specification corpus, hackathon, Natively AI, Python backend.

1.3. Executive Summary
game_specifications/ contains twenty-five files (this index, the documentation-standards
baseline at 0000, and twenty-three topical specification files numbered 001 through 024).
Every topical file is either a game-design document (concept, aesthetics, philosophy, menus,
modes, rules, player statistics, wishlist) or a software-engineering standards document
(coding standards, scaffolding, virtual environment, testing tiers, CICD, deployment, data
structures/algorithms, logging, data formats, visualization, modules/imports, naming
conventions) for the Python backend that implements X Paradox X. This index gives any agent
or contributor a single entry point to locate the authoritative source for any question about
the game or its implementation, and to verify that no file has been left empty or non-compliant.

1.4. Key Findings
1.4.1. The corpus splits cleanly into two functional tracks: Game Design (001-004, 010,
016-018) and Software Engineering (005-009, 011-015, 019, 023, 024) with three
cross-cutting technical-standards documents (020, 021, 022) shared by both tracks.
1.4.2. As of this revision, all twenty-three topical files have been brought into full
compliance with game_specifications/0000_documentation_standards.txt.
1.4.3. Five files (005, 008, 020, 021, 022) carried pre-existing baseline notes authored
before this revision; per 0000_documentation_standards.txt's binding instruction that "no
agent must remove any existing texts in any files," those notes were preserved verbatim and
incorporated as the seed content of their respective document bodies.
1.4.4. This repository (DarkStrategy_XParadoxX, marked with py.typed) is the authoritative
Python backend implementation target for the LabLab AI Factory / Natively AI hackathon
submission, not a disposable planning-only artifact.
1.4.5. Canonical game mechanics were revised during this documentation pass relative to the
earliest ChatGPT ideation record (chatGPT_records/chat_record_30072026.md); see the
Reconciliation Table (1.8) and 001_game_concept.txt Section 1.8 for the authoritative diff.

1.5. Philosophical Preamble
An index is the map of a territory, not the territory itself; yet a strategy game that
concerns itself with the capture, ownership, and reconciliation of territories owes its own
documentation the same discipline it demands of its players. To leave a specification file
empty is to leave a tile unclaimed and undefended on the board of the project itself. This
index exists so that no contributor — human or agent — ever again asks "where is this
documented?" without an immediate, authoritative answer.
