SOLID, ACID, JPL 10 FP, Clean Code, modularized codes, no single file doing too much. Def main only a few lines of code. Documentation with WHAT, WHY, HOW, args, throws, returns, Time and Space complexity analysis. For python specifically: if __name__ == "__main__": main() should be the only code outside of functions and classes. No global variables, no magic numbers, no hardcoded strings, no hardcoded paths. Use constants and configuration files. Use type hints for function arguments and return types. Use logging instead of print statements. Write unit tests for all functions and classes. Use virtual environments for dependencies. Follow PEP 8 style guide for Python code. The entry point must be only a few lines of raw code. Every python file must have it. Likewise, other programming languages all follow this example where appropriate. Use version control (git) with meaningful commit messages. Use branching strategies for features, bug fixes, and releases. Write clear and concise commit messages. Use code reviews to maintain code quality. Use continuous integration and continuous deployment (CI/CD) pipelines for automated testing and deployment.
