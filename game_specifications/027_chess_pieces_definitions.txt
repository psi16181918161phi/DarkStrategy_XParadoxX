1.1. Abstract
This document defines the chess piece vocabulary used by X Paradox X, including movement,
combat-stat interpretation, and role semantics for gameplay and implementation. It is a
reference companion to 017_game_rules.txt Sections 1.7 and 1.11.

1.2. Key Words
King, Queen, Rook, Bishop, Knight, Pawn, movement legality, combat stats, role taxonomy,
board scaling, Dark Strategy.

1.3. Executive Summary
X Paradox X uses standard chess pieces with standard movement legality, combined with custom
combat stat blocks to support dice-based combat and territory control. This file clarifies
piece-level definitions so menus, tooltips, AI adviser prompts, and tests all use one
canonical vocabulary.

1.4. Key Findings
1.4.1. Piece names are canonical and cannot be aliased in core game text.
1.4.2. Movement legality follows standard chess movement patterns.
1.4.3. Combat values are interpreted as Attack, Defence, and Health attributes in combat.
1.4.4. Piece roles in this game are functional/gameplay roles, not classical chess theory roles.

1.5. Philosophical Preamble
Borrowing familiar movement from chess lowers onboarding friction, while adding stat-driven
combat and territory economics creates the "paradox" identity of the game.

1.6. Scope and Authority
1.6.1. This file defines terms and role semantics.
1.6.2. Numeric stat values are sourced from 017_game_rules.txt and repeated here as reference.
1.6.3. If a numeric mismatch appears, 017_game_rules.txt is authoritative.

1.8. Movement Definitions
1.8.1. King: one square in any direction.
1.8.2. Queen: any number of squares along rank, file, or diagonal.
1.8.3. Rook: any number of squares along rank or file.
1.8.4. Bishop: any number of squares along diagonal.
1.8.5. Knight: L-shape jump (two in one axis, one in the orthogonal axis).
1.8.6. Pawn: one square forward (two from initial position if legal), captures diagonally.
1.8.7. Rule simplification note: special chess rules such as castling and en passant are
deferred unless explicitly added to canonical rules in future revisions.

1.9. Combat Stat Definitions
1.9.1. Attack: base offensive value added to the attacker d6 roll.
1.9.2. Defence: base defensive value added to the defender d6 roll.
1.9.3. Health: hit-point pool; piece is removed at 0 HP.
1.9.4. Canonical reference values:
| Piece | Attack | Defence | Health |
|-------|--------|---------|--------|
| King | 2 | 3 | 6 |
| Queen | 4 | 2 | 5 |
| Rook | 3 | 3 | 5 |
| Bishop | 2 | 2 | 4 |
| Knight | 3 | 2 | 4 |
| Pawn | 1 | 1 | 2 |

1.10. Piece Roles in X Paradox X
1.10.1. King: strategic anchor and high-value target.
1.10.2. Queen: primary pressure unit for decisive attacks.
1.10.3. Rook: frontline control and resilient contest unit.
1.10.4. Bishop: support and upgrade-builder role (per 017_game_rules.txt Section 1.7.4).
1.10.5. Knight: tactical disruptor for positional forks and surprise pressure.
1.10.6. Pawn: low-cost map-control and attrition unit.

1.11. Board-Size Scaling Notes
1.11.1. Piece counts scale by board size per 017_game_rules.txt Section 1.7.1.1.
1.11.2. Role semantics do not change with board size, only piece quantities and spacing.
